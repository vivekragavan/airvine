# airvine

Static snapshot of www.airvine.com (WordPress on WP Engine), taken 2026-11-12, used as a working copy for proposed site changes.

Preview: https://vivekragavan.github.io/airvine/

- Site files are at the repo root (served by GitHub Pages under `/airvine/`).
- `tools/mirror.py` re-crawls the live site: `python3 tools/mirror.py <outdir> /airvine/`.
- Forms (HubSpot) and other dynamic WordPress features do not work in this static copy.
